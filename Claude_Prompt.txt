Build a credible, clickable front-end prototype called a "Fan Intelligence Platform" — an internal tool for the Irish Football Association (Northern Ireland) commercial team to understand supporters of the Women's Senior Team and act to bring first-time attendees back for a second match. Primary user: the Fan Engagement Manager; secondary: Head of Sales & Marketing. It is a high-fidelity shell demonstrator with illustrative mock data (no live integrations), EXCEPT for one real dataset (match attendance) described below.
TECH & DEPLOYMENT
- React 18 + Vite (plain JSX, no TypeScript), React Router (client-side routing), Recharts for charts, lucide-react for icons, d3-geo + topojson-client for the map. Plain CSS design system in src/index.css (no CSS framework).
- Deployable to Vercel and Netlify: include vercel.json and netlify.toml with SPA fallback rewrites (all routes -> index.html), build command "npm run build", output "dist".
- Include a README describing the project, the honest "illustrative data / one real dataset" framing, and deploy steps. .gitignore for node/dist.
BRANDING & DESIGN SYSTEM
- Irish-FA-green palette; clean, modern SaaS look; light theme; system-ui font. Cards with subtle borders/shadows, rounded corners, KPI "stat" tiles, badges/pills, chips, tables with hover, meters/bars.
- Charts must use a colourblind-safe categorical palette (blue, orange, aqua, yellow, magenta, green, violet, red) with a shared custom tooltip; compact "k" axis formatting so 4–5 digit values aren't clipped.
- Left sidebar (dark green) with brand: title "Fan Intelligence", subtitle "Irish FA · Women's Team", and the IFA crest on a white chip (load /ifa-crest.png via a Logo component that falls back to a shield icon if missing). Sidebar nav grouped:
  • Overview: "Fanbase Overview" (/), "Alerts & Insights" (/alerts, with a count badge)
  • Fans: "Fan Segmentation" (/segments), "Fan 360 Profiles" (/fans)
  • Engagement: "Campaigns & Content" (/campaigns), "Match-day / Opta" (/matches), "Revenue & Monetisation" (/revenue)
  • Platform: "Data Sources" (/sources)
- Top bar: current page title + breadcrumb "Irish Football Association · Women's Senior Team"; NO search box and NO season control; an alerts bell that navigates to /alerts; a round avatar showing the IFA crest (fallback text "IFA"). Favicon = the crest.
DATA-SCALE MODEL (keep everything internally consistent & proportionate to real ~2,000 home crowds)
- ~21,500 unified fan profiles; ~11,900 known attendees; ~7,350 monthly active (34%); ~31.5k social followers; ~£308k season fan revenue (ticketing ~£152k from ~12,600 attendances at realistic yields, plus retail/F&B/memberships/hospitality). Fan LTV ~£96; revenue per fan ~£14; avg concourse spend/attendee ~£8.40. Document these assumptions in a comment at the top of the overview data file. Do NOT use inflated figures like 48k fans / £2.7m / 200k followers.
